# Cybersecurity Fundamentals

These notes summarize the cybersecurity fundamentals I studied through IBM training and my own practice.

## Core Security Concepts

Cybersecurity focuses on protecting systems, networks, applications, and data from unauthorized access, attacks, damage, and disruption.

### CIA Triad

The CIA triad represents three important security goals:

- **Confidentiality** — information should only be accessible to authorized users.
- **Integrity** — information should not be changed or manipulated without authorization.
- **Availability** — systems and information should remain accessible when needed.

## Threats, Vulnerabilities, and Risk

- **Threat** — something that could cause harm to a system or organization.
- **Vulnerability** — a weakness that could be exploited.
- **Risk** — the potential impact and likelihood of a threat exploiting a vulnerability.

Understanding the difference between these concepts is important when evaluating the security of a system.

## Authentication and Access Control

Authentication verifies the identity of a user or system.

Access control determines what an authenticated user is allowed to access or perform.

Some important concepts include:

- Strong passwords
- Multi-factor authentication
- Permissions
- Least privilege

## Network Security

Network security focuses on protecting network traffic, devices, and services from unauthorized access and attacks.

Concepts I have studied include:

- Firewalls
- Network protocols
- Secure communication
- Network monitoring
- Common network-based threats

## Common Cybersecurity Threats

Examples of threats I have studied include:

- Phishing
- Malware
- Social engineering
- Password attacks
- Denial-of-Service attacks
- Man-in-the-middle attacks

## Security Practices

Some important security practices include:

- Keeping systems and software updated
- Using strong authentication
- Limiting unnecessary privileges
- Monitoring systems and networks
- Maintaining backups
- Identifying and addressing vulnerabilities

## Key Takeaways

- Security is not only about preventing attacks, but also reducing risk and limiting their impact.
- Confidentiality, integrity, and availability are fundamental security goals.
- Vulnerabilities can become security risks when they can be exploited by threats.
- Authentication and authorization serve different purposes.
- Layered security controls provide stronger protection than relying on a single defense.
